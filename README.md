## 2026-11 화면 정리 내용

- 글씨: 제목·본문 자간과 행간을 정리하고, 너무 작던 설명 글씨(11~12px)를 12.5~14px로 키움. 흐린 회색 글씨는 더 진하게.
- 누르는 곳: 버튼·입력칸·선택칸 높이를 손가락으로 누르기 쉬운 크기(42~46px)로 통일. 휴대폰에서 입력칸을 눌러도 화면이 확대되지 않게 글씨 16px.

- 내신 계산기: 좁은 화면 아래에 "성적 입력 / 결과 / 전형별 상세" 바로가기 막대. 결과 카드가 휴대폰에서 2칸+1칸으로 배치. 옆으로 넘기는 표는 가장자리 그림자로 표시.
